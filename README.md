# 捷運迷因冒險

手機直式、固定對話與四款限時小遊戲的純前端 MVP。

以 `PLAN.md` 為玩法規格。實作採原生 JavaScript + DOM/CSS，不需後端或打包工具。
老人正式素材只使用 `elder-potbelly-v12.png`；舊版老人與車廂 v1 素材已移除。

## 開發步驟

- [x] 建立版本控制與 MVP 決策
- [x] 四款遊戲邏輯與計分驗證
- [x] 對話、挑戰與結算流程
- [x] 圖片、音效與分享卡
- [x] 桌面與手機尺寸瀏覽器驗收
- [ ] 實體手機觸控、分享與節奏驗收

暫定文案與名稱由 MVP 補齊，可後續修改。老人採「踢當下位置」；三種結果沿用 160／280 分門檻。

執行 `npm test` 驗證核心邏輯；`npm start` 啟動本機伺服器（http://127.0.0.1:5173）。

MVP 美術：老人與車廂沿用既有 PNG，其他人物採 CSS 分層圖形，道具採本地 SVG；無外部素材或服務依賴。

驗收紀錄見 [docs/QA.md](docs/QA.md)。已完成桌面與手機尺寸的瀏覽器驗收；實體手機觸控、原生分享與實際遊玩節奏仍待確認。

本機除錯：`http://127.0.0.1:5173/?stage=legs&seed=1`，可指定 elder、odor、legs、crowd；此入口僅在本機網域啟用。

部署時將 `index.html`、`src/`、`assets/` 放到任意靜態網站服務即可，不需要建置或伺服器 API。
