# 美術素材索引

執行時圖片放在 `assets/`；所有提示詞集中在本目錄的 `prompts/`，依 characters、backgrounds、props 分類，以相同檔名對照圖片。

| 用途 | 位置 |
| --- | --- |
| 五關對話完整情境圖 | `assets/backgrounds/dialogue/{urine,elder,odor,legs,crowd}-v1.png` |
| 簡潔遊戲背景與首頁 | `assets/backgrounds/` |
| 遊戲角色 | `assets/characters/` |
| 道具、臭氣、特效 | `assets/props/` |
| 原始多角色圖集 | `assets/sources/characters/` |
| 已替換舊角色 | `assets/archive/characters/` |

對話插畫包含角色與完整情境，不再將遊戲角色疊在通用背景上。遊戲維持獨立角色與簡潔背景，以利辨識互動目標。

提示詞由 built-in imagegen 使用。原始圖集的裁切說明保留於對應 prompt 文件；歷史文件內的素材路徑代表當時位置，請以本索引為準。
