# 現行遊戲規格

台北捷運奇遇記，原生 JavaScript + DOM/CSS，手機直式優先。

| 關卡 | 規則 | 對話情境圖 |
| --- | --- | --- |
| 接尿 | 12 秒、18 滴，左右接尿 | 花襯衫乘客朝綠色座椅排尿 |
| 老人 | 15 秒、12 次命中，4／8／12 次換圖 | 坐著的玩家面對要求讓座的阿伯 |
| 消臭 | 25 秒、54 團，逐漸加速 | 坐在對面的大哥與迎面臭氣 |
| 合腿 | 25 秒、70 次，提前完成加分 | 玩家坐在張腿乘客旁邊，被擠到沒空間 |
| 下車 | 24 秒、32 波，兩道阻擋一道空隙 | 人群搶上車，堵住想下車的主角 |

五關各 100 分、總分 500；結算門檻 200／350。main 為完整五關；release/v1 為既有兩關部署版。

首頁使用專屬捷運站外背景、疲憊中年上班族、台北捷運奇遇記與點擊開始。每關對話使用完整專屬 Wojak 情境插畫，遊戲使用簡潔背景加角色與互動物件。
